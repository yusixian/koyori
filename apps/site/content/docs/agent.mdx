Agent 的首个开发切片支持自配模型的文字对话。会话保存在本机；发送消息时，当前会话中可继续的对话会交给你选择的模型服务。Skills 管理可以独立使用。

个人 Bot 的设备配对、Skills 附件与操作卡、长期偏好和语音仍待实现。当前没有公开发行安装包，使用方式见[本地开发](/docs/development)。

## 配置连接

进入 **Agent**，填写连接名称、服务地址和模型。当前支持 OpenAI-compatible 的 Chat Completions 流式接口；服务地址填写 API 基址，例如 `https://model.example/v1`，应用会追加 `/chat/completions`。模型标识由你的服务提供方给出。

外部服务要求 HTTPS；本机服务可使用 `http://localhost:端口/v1`、`http://127.0.0.1:端口/v1` 或 IPv6 回环地址。当前不支持其他局域网地址。服务地址不能包含账号、密码、查询参数或片段，也不跟随重定向。

需要鉴权时填写 API Key。密钥使用操作系统提供的安全存储能力加密后保存在本机，不会回显到设置页。应用启动和浏览会话不访问钥匙串；保存非空密钥或使用已保存密钥发送消息时，系统可能请求授权。取消授权或安全存储不可用时会报错，不会改用明文保存；恢复后可以重新尝试。无需密钥的本机服务可以留空。

**保存连接只保存设置，不测试模型、不产生推理请求。** 点击发送后才会调用所选服务，可能产生该服务的费用。

## 会话与发送范围

- 新建会话后输入文字并发送，回复会逐段显示。只发送当前会话的文字，不自动附加 Skills、目录、使用账本或其他应用的历史。
- 会话支持切换、重命名和删除。删除只影响本机记录，不代表删除了模型服务保留的数据。
- 修改并保存连接会创建新的连接身份和会话。旧会话保留供查看，不能继续发送到新连接。
- 当前一次运行一条回复。切换页面保留未发送的草稿；退出应用后仅已保存的会话记录保留。

回复按纯文本显示，不执行 HTML、脚本或模型提出的操作。需要处理文件的建议应由你审阅；当前 Agent 没有本机写入工具。

## 停止、错误与用量

点击 **停止生成** 会停止接收回复并取消请求，已收到的文字保留。取消不能保证服务端尚未发生费用。失败、取消或应用退出中断的回复会显示对应状态，不伪装为完整答案。

请求失败后不会自动重试或切换服务。确认连接与服务状态后，可以手动再次发送。应用重启保留本地会话，并把未结束的生成标为中断。

服务提供输入和输出 token 时显示其报告值；缺失时保持未知。当前不推算费用或节省金额。

## 验证范围

协议、流式响应、错误和取消使用合成本机服务验收。该结果不代表所有声明兼容的模型服务都已验证；真实服务的鉴权、计费和模型能力需在你明确选择后分别确认。
