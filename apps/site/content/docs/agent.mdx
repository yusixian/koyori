Agent 的首个开发切片支持自配模型的文字对话。会话保存在本机；发送消息时，当前会话中可继续的对话会交给你选择的模型服务。Skills 管理可以独立使用。

开发版支持从 Skills 资源清单发起单项讨论，并为所选 Skill 生成“始终保留”或“30 天后复查”本地操作卡。个人 Bot 的设备配对、通用工具操作卡、长期偏好和语音仍待实现。桌面 Preview 的安装和更新方式见[安装说明](/docs/installation)，源码开发方式见[本地开发](/docs/development)。

## 配置连接

进入 **Agent**，点击 **连接设置**，填写连接名称、服务地址和模型。当前支持 OpenAI-compatible 的 Chat Completions 流式接口；服务地址填写 API 基址，例如 `https://model.example/v1`，应用会追加 `/chat/completions`。模型标识由你的服务提供方给出。

填好服务地址后可点击 **测试连接** 或 **获取模型**。两项操作都会向该基址的 `/models` 发出一次 `GET` 请求；不会发起推理请求或保存草稿。获取模型会列出服务返回的模型 ID，点选后仍须保存连接。通过测试仅证明模型列表接口可达并返回兼容格式，不保证所选模型支持对话。有些服务不提供这个列表接口，此时仍可手动填写模型 ID；若服务使用其他模型列表路径，当前版本尚不支持修改路径。

外部服务要求 HTTPS；本机服务可使用 `http://localhost:端口/v1`、`http://127.0.0.1:端口/v1` 或 IPv6 回环地址。当前不支持其他局域网地址。服务地址不能包含账号、密码、查询参数或片段，也不跟随重定向。

需要鉴权时填写 API Key。密钥使用操作系统提供的安全存储能力加密后保存在本机，不会回显到设置页。应用启动和浏览会话不访问钥匙串；保存非空密钥、测试连接或使用已保存密钥发送消息时，系统可能请求授权。相同服务地址下留空密钥可沿用已保存密钥；更改服务地址时须重新填写，避免把原密钥发送到新目标。取消授权或安全存储不可用时会报错，不会改用明文保存；恢复后可以重新尝试。无需密钥的本机服务可以留空。

**保存连接只保存设置，不测试模型、不产生推理请求。** 点击发送后才会调用所选服务，可能产生该服务的费用。

## 从一项 Skill 开始讨论

这条流程目前只支持单项 Skill。你可以从资源清单选中一项，点击和 Koyori 讨论；主进程会按当前选定的观察窗口生成一份完整预览。预览只包含白名单摘要：Skill 名称、客户端、观察窗口、已观察次数及证据缺口、保留/复查状态和规则类型。

名称可能包含项目或组织信息。请先审阅摘要，再决定是否加入当前可编辑草稿；已有草稿内容会保留，新摘要追加在末尾，加入前可丢弃摘要，加入后可在草稿中删除。只有你手动点击发送后，文字才会交给当前模型服务；准备摘要不会自动请求模型。

预览中的“返回使用证据”会打开所选 Skill 的使用账本证据区，并使用生成摘要时的观察窗口。你可以核对记录后回到 Agent；摘要和已有草稿仍会保留。若没有可核对的记录，账本会说明；若 Skill 来源已不可用，预览会提示重新扫描。

摘要使用生成时的统计快照，之后统计变化不会自动改写草稿。未知、同名待归属和暂停状态会在摘要中保留解释。当前不发送 Skill 正文、描述、路径、原始会话或其他资源信息，也不提供多选、全文附件或把证据文件位置附入摘要。

在这项 Skill 的 Agent 区域，你可以点选“始终保留”或“30 天后复查”，查看当前偏好与确认后的完整结果，再明确确认。前者会清除复查日期；后者会取消始终保留并把复查日期设为生成操作卡后的第 30 天。卡片五分钟内有效；保存前主进程重新核对资源、Skill 文件状态和当前偏好，变化时拒绝并要求重新预览。模型回复不能替你点选、修改或授权操作卡；这项本机偏好操作不向模型服务发送数据，也不更改 Skill 文件。

## 会话与发送范围

- 新建会话后输入文字并发送，回复会逐段显示。只发送当前会话的文字，不自动附加 Skills、目录、使用账本或其他应用的历史。
- 会话支持切换、重命名和删除。删除只影响本机记录，不代表删除了模型服务保留的数据。
- 修改并保存连接会创建新的连接身份和会话。旧会话保留供查看，不能继续发送到新连接。
- 当前一次运行一条回复。切换页面保留未发送的草稿；退出应用后仅已保存的会话记录保留。

回复按纯文本显示，不执行 HTML、脚本或模型提出的操作。当前仅有上述用户主动选择并确认的本地偏好操作卡；Agent 没有文件写入工具。

## 停止、错误与用量

点击 **停止生成** 会停止接收回复并取消请求，已收到的文字保留。取消不能保证服务端尚未发生费用。失败、取消或应用退出中断的回复会显示对应状态，不伪装为完整答案。

请求失败后不会自动重试或切换服务。确认连接与服务状态后，可以手动再次发送。应用重启保留本地会话，并把未结束的生成标为中断。

错误会注明失败阶段。DNS 阶段被拦截时，尚未发送 HTTP 请求，因此没有接口状态码或响应；HTTP 失败会显示状态码，以及服务返回的标准 `error.code`、`error.type`、`error.message` 字段（经过长度限制与密钥脱敏）。任意 HTML 或非标准响应体不会原样显示。部分本机代理会把外部 HTTPS 域名解析到虚拟地址段；应用只对这类域名的解析结果做有限兼容，仍验证 HTTPS 证书，不接受直接填写该地址或其他内网地址。

服务提供输入和输出 token 时显示其报告值；缺失时保持未知。当前不推算费用或节省金额。

## 验证范围

协议、流式响应、错误和取消使用合成本机服务验收。摘要讨论使用合成资源与本机服务核对实际发送内容；真实付费模型服务尚未测试。上述结果不代表所有声明兼容的模型服务都已验证，真实服务的鉴权、计费和模型能力需在你明确选择后分别确认。
