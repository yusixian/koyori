Koyori 是一个自用优先、从首版按开源方式建设的 AI Native 个人工作台。首个平台是 macOS / Electron，当前从 **Skills + 个人 Agent** 两条主线起步。

> 当前开发版可自动发现 Claude Code 与 Codex Skills，预览并执行完整目录同步，建立本地恢复快照；Claude Code 使用证据可在用户开启后持续更新。个人 Agent 已支持自配模型的本地文字会话、流式回复和取消；“我的服务”可登记本机书签并在系统默认浏览器中打开。桌面 Preview 是否可下载，以[下载页](/download)的公开清单为准。

## 从哪里开始

- [安装](/docs/installation)：查看 macOS Preview 的安装、手动更新与签名限制。
- [Skills 发现、同步与备份](/docs/skills-management)：了解自动检测范围、安全同步、本地快照与恢复。
- [Skills 使用统计](/docs/skill-usage)：连接历史、核对证据与设置整理偏好。
- [自配模型与文字对话](/docs/agent)：配置 OpenAI-compatible 连接，管理本地会话并查看流式回复、取消和用量状态。
- [我的服务](/docs/services)：登记 HTTPS 或本机开发服务入口，并在系统浏览器中打开。
- [本地开发](/docs/development)：查看当前工具链、文档站命令和贡献前提。
- [安全与数据](/docs/security)：了解本地文件、凭据、授权和安全报告边界。

## Koyori 准备解决什么

AI 工具的 Skills、MCP、commands 和项目指令往往散落在不同目录与客户端中。Koyori 希望先把它们的来源、作用域和变化整理清楚，再提供可审阅、可恢复的操作。

首版不会顺手扩展成团队平台、插件市场或通用云服务。功能范围会随真实自用流程逐个验证。

## 文档发布规则

公开站点只构建这个显式内容目录。仓库根目录中的设计记录不会自动变成使用指南；每项能力只有在实现并验证后，才进入正式文档。
