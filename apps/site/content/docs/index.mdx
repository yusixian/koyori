Koyori 是一个自用优先、从首版按开源方式建设的 AI Native 个人工作台。首个平台是 macOS / Electron，当前从 **Skills + 个人 Agent** 两条主线起步。

> 当前已有可运行的只读 Skills 工作台与 CLI：支持选择目录、扫描、筛选和预览，并已完成本地候选验证。安装包尚未公开发布；调用统计、整理写入与个人 Agent 接入仍在继续迭代。

## 从哪里开始

- [安装](/docs/installation)：查看为什么现在还没有下载入口，以及首个安装包会如何验收。
- [本地开发](/docs/development)：查看当前工具链、文档站命令和贡献前提。
- [安全与数据](/docs/security)：了解本地文件、凭据、授权和安全报告边界。

## Koyori 准备解决什么

AI 工具的 Skills、MCP、commands 和项目指令往往散落在不同目录与客户端中。Koyori 希望先把它们的来源、作用域和变化整理清楚，再提供可审阅、可恢复的操作。

首版不会顺手扩展成团队平台、插件市场或通用云服务。功能范围会随真实自用流程逐个验证。

## 文档发布规则

公开站点只构建这个显式内容目录。仓库根目录中的设计记录不会自动变成使用指南；每项能力只有在实现并验证后，才进入正式文档。
