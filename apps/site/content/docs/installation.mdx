## 当前状态

当前公开版为 v0.1.0-alpha.4，使用 Apple Development 签名、未公证。首次安装使用 DMG；后续 Preview 的实际更新方式以[下载页](/download)所列版本为准。

首版面向 macOS 13+ 的 Apple Silicon Mac。下载页会显示公开版本、系统要求、签名状态、文件大小、SHA-256 和 GitHub Release。

[查看下载状态](/download)

## 安装方式

首次安装：在[下载页](/download)点击“下载 DMG”，打开 DMG，将 Koyori 拖到 Applications，再从 Applications 打开。若已运行旧版本，先退出再替换。

标记为手动安装的版本需要先退出旧版，再通过新版 DMG 替换。下载页明确标记“应用内更新”的已签名版本，才支持在应用中检查、下载并确认重启安装；Apple Development 签名的 Preview 仍未公证。

## 更新流程

v0.1.0-alpha.1 不包含更新源配置，必须从下载页取得新版 DMG 并手动替换一次。安装带更新源的新版后，应用会自动检查后续新版，也可以点击侧栏的 **更新**，在独立页面手动检查、下载和重启安装。当前任务未结束时，应用会提示稍后再安装，并在退出前保存 Agent 数据。

下载页的版本信息、DMG 地址和 SHA-256 来自同一份公开清单，GitHub Release 提供对应的完整更新说明。当前不会在后台静默安装、替换或重启应用。

如果 macOS 提示“Koyori.app 已损坏，无法打开”，请先核对官方 Release 下载来源和 SHA-256，再按[下载页的首次打开 FAQ](/download#damaged-app)处理。

## Preview 限制

Preview 面向 macOS 13+ Apple Silicon，用于本机测试，不承诺 Intel 原生支持或跨平台安装。未公证版本会按实际签名状态标记，可能需要在 macOS“隐私与安全性”中手动允许打开。应用内更新由安装包中的更新源配置决定；alpha.1 没有该配置，需手动替换。公开下载只在同一候选完成安装验收与产物校验后开放。

每份公开清单都绑定版本、构建 commit、文件大小和 SHA-256。重新构建后的文件即使版本号相同，也不能沿用之前文件的校验结果。
