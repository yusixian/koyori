## 当前状态

Koyori **还没有已发布的安装包**。下载页不会提供空链接，也不会将本地开发构建标记为公开版本。

[查看下载状态](/download)

## 首发平台

首版面向 macOS，具体最低系统版本和 CPU 架构仍要由打包与实际设备验收确认。在这些结论产生前，文档不会提前承诺兼容范围。

## 安装包发布后

首个可下载版本会同时说明：

- 产品版本、发布渠道与对应 commit；
- macOS 版本和架构要求；
- 签名与公证的真实状态；
- SHA-256 摘要和已知限制；
- 如果需要手动放行，提供准确步骤并明确 preview 属性。

验收会针对最终上传的同一份产物进行。重新构建后的文件即使版本号相同，也不能沿用之前的验收结果。
