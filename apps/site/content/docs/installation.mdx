## 当前状态

首个 macOS Preview 正在准备安装检查，目前尚未开放下载。首发可采用明确标记的 Apple Development 已签名、未公证手动安装包；Developer ID 签名和公证完成后再开放应用内更新。

首版面向 macOS 13+ 的 Apple Silicon Mac。开放下载后，下载页会显示版本、系统要求、签名状态、文件大小、SHA-256 和 GitHub Release。

[查看下载状态](/download)

## 安装方式

首次安装：在[下载页](/download)点击“下载 DMG”，打开 DMG，将 Koyori 拖到 Applications，再从 Applications 打开。若已运行旧版本，先退出再替换。

标记为手动安装的版本需要先退出旧版，再通过新版 DMG 替换。只有下载页明确标记“应用内更新”的签名、公证版本，才支持在应用中检查、下载并确认重启安装。

## 更新流程

手动安装版不包含更新源配置；请从下载页获取新版 DMG 并自行替换。签名、公证版启用更新源后，应用才会自动检查新版，也可以在“更新”面板手动检查、下载和重启安装。当前任务未结束时，应用会提示稍后再安装，并在退出前保存 Agent 数据。

下载页的版本信息、DMG 地址和 SHA-256 来自同一份公开清单，GitHub Release 提供对应的完整更新说明。当前不会在后台静默安装、替换或重启应用。

## Preview 限制

首个 Preview 面向 macOS 13+ Apple Silicon，用于本机测试，不承诺 Intel 原生支持或跨平台安装。未公证版本会按实际签名状态标记，可能需要在 macOS“隐私与安全性”中手动允许打开；它不具备应用内自动更新。公开下载只在同一候选完成安装验收与产物校验后开放。

每份公开清单都绑定版本、构建 commit、文件大小和 SHA-256。重新构建后的文件即使版本号相同，也不能沿用之前文件的校验结果。
