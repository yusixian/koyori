## 本地数据

用户文件始终是权威来源。计划中的写入流程会先生成可审阅计划、核对文件 revision、准备恢复材料，再执行并回读验证。自动发现不会自动启用、上传、运行或删除资源。

## 凭据与外部连接

凭据应保存在系统安全存储或服务端安全引用中，不交给无关页面或模型。外部连接按服务、账号和能力隔离，并允许撤销。

当前没有已发布应用，因此以上是工程必须满足的边界，不代表相关功能已经完成安全验收。

## 权限原则

- 本机调用不自动拥有所有写入权限。
- 模型输出、网页、日志和 Skill 文本不能授予执行权限。
- renderer 不获得通用文件、shell 或 IPC 能力。
- 远程内容与本地工作台权限隔离。

## 报告安全问题

请通过 GitHub 的 [私密漏洞报告入口](https://github.com/yusixian/koyori/security/advisories/new) 报告安全问题。不要在公开 issue 中粘贴密钥、令牌、真实会话或其他敏感信息。

一般问题可以查看 [GitHub 仓库](https://github.com/yusixian/koyori) 并使用公开 issue。
