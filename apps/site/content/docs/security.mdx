## 本地数据

用户文件始终是权威来源。自动发现只登记已知目录，不会自动启用、上传、运行或删除资源。同步和恢复会先生成可审阅计划，执行前重新核对真实路径与 revision；替换前保存本地恢复快照，写入后重新读取验证。目标被外部修改或链接接管时，操作停止并留下记录。

本地快照包含完整 Skill 目录，属于用户数据。便携快照会去掉原位置等本机绝对路径，只保留相对目录、内容和摘要；它不会自动包含使用账本、原始会话或凭据。Git 远端备份仍需单独配置和明确触发，本地快照不等于已经上传。

## 凭据与外部连接

凭据应保存在系统安全存储或服务端安全引用中，不交给无关页面或模型。外部连接按服务、账号和能力隔离，并允许撤销。

公开 Preview 的签名与安装方式按实际候选标注；未签名版本仅支持手动安装。下载页展示的 SHA-256、构建 commit 和安装限制来自公开清单。源码检查或 CI 结果不能替代最终安装包验收，也不能证明未签名文件的发布者身份。

“我的服务”只在本机保存链接；打开时交给系统默认浏览器，不会把远程网页嵌入 Electron。外部地址限 HTTPS，本机 HTTP 仅接受 loopback；保存链接不代表已认证或授权对应服务。

## 权限原则

- 本机调用不自动拥有所有写入权限。
- 模型输出、网页、日志和 Skill 文本不能授予执行权限。
- renderer 不获得通用文件、shell 或 IPC 能力。
- 远程内容与本地工作台权限隔离。

## 报告安全问题

请通过 GitHub 的 [私密漏洞报告入口](https://github.com/yusixian/koyori/security/advisories/new) 报告安全问题。不要在公开 issue 中粘贴密钥、令牌、真实会话或其他敏感信息。

一般问题可以查看 [GitHub 仓库](https://github.com/yusixian/koyori) 并使用公开 issue。
