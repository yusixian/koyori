本功能保留在本机运行，不需要模型账户。Koyori 会发现可能的历史目录，但只有你选择目录并开启自动统计后才读取内容。

## 开启自动统计

1. 先在资源清单确认 Claude Code Skills 来源，然后切换到 **使用与建议**。
2. 在“让使用证据持续更新”中选择一个已发现的 Claude Code 历史目录，点击“开启所选目录的自动统计”。默认配置通常对应 `~/.claude/projects`；使用 `CLAUDE_CONFIG_DIR` 时以实际配置目录为准。
3. 开启后会立即检查一次。应用启动补扫，运行期间约每 30 秒检查一次；界面显示最近尝试时间、日志覆盖及读取提示，可切换近 30 / 90 天。
4. 展开某项资源的证据，核对相对日志文件、行号、时间和结果。重复检查会去重，并补齐后来出现的结果。

自动统计默认关闭。只读取主动勾选的目录，不安装 hooks、不运行 Skill、不修改原日志。暂停自动统计或断开来源会停止后续读取，但已采集记录仍保留在本机。也可以继续使用“手动连接历史”选择更小的项目目录。

Codex 的会话目录可能出现在候选列表中，但当前只支持资源清单，**尚不支持历史调用统计**，因此不能勾选。其未采集状态不会显示为零调用。

逐资源账本先显示有使用线索、保留偏好或复查建议的 Skill。点击“查看全部”仍可检查未采集的资源；未显示不表示零调用。

## 从资源清单讨论一项 Skill

开发版支持 Skills → Agent 的单项讨论。选择资源清单中的一项 Skill 后，可以让 Koyori 生成当前统计快照的完整预览；主进程只提供白名单摘要：名称、客户端、观察窗口、次数及证据缺口、保留/复查状态和规则类型。

摘要名称可能包含私密项目或组织信息，请先审阅。已有 Agent 草稿会保留，摘要只追加到当前可编辑草稿；加入前可丢弃摘要，加入后可在草稿中删除。准备摘要不会自动请求模型，只有手动发送后才会进入当前会话。发送内容不包含 Skill 正文、描述、路径、原始会话或其他资源信息。

统计快照生成后不会随账本变化自动更新。未知、同名待归属和暂停状态会保留说明；当前只支持一项 Skill，不支持多选、全文附件或证据引用跳转。整理建议不提供操作卡，也没有执行权限。

## 数字表示什么

| 指标 | 含义 |
| --- | --- |
| 调用尝试 | 可识别的结构化 Skill 工具事件，复制记录只计一次 |
| 成功返回 | 找到对应工具结果且未标记错误，不证明任务成功 |
| 失败 | 对应结果标记错误 |
| 结果未知 | 缺少结果或存在冲突 |
| 显式请求 | 识别到直接命令请求，独立于工具调用计数 |
| 会话 | 能确认归属的会话数；归属冲突时只作为下限 |

提及 Skill 名称、显示资源列表、读取 SKILL.md 都不计调用。当前文件按来源、客户端与精确名称关联；同名无法唯一归属的事件显示在未归因排行中。

“0 次”只代表选定可读记录中未观察到调用。记录日期跨度不证明期间完整，更不代表该 Skill 从未使用。请同时阅读覆盖、读取限制及最近导入时间。

## 保留与复查

- **始终保留**：从闲置、低频和相同内容整理候选中保护这项资源。
- **30 天后复查**：保存提醒日期，也可以清除。
- **规则**：默认闲置 90 天、低频上限 2 次、新发现观察期 30 天，可按需要调整。
- **本次已复查**：记录人工检查时间，应用内每七天提醒再次查看。

新发现日期不是安装日期。闲置/低频规则要求记录跨度达到所设观察期、起点覆盖该窗口、最新记录在近七天内（观察期不足七天时按该天数），且本次读取未受限制；证据不足时不生成该类候选。相同内容候选只比较完整文件，排除指向同一实际文件的链接。所有建议都需要自己判断；当前没有自动归档、删除或 AI 推荐调用。

## 数据与排障

应用数据目录里的 `usage.json` 保存最小使用事件、来源位置和偏好，`.bak` 保留上一份账本。`usage.json.collection` 保存自动统计开关和选中的候选目录。它们是个人数据，不是缓存，不应贴到公开 issue。账本不保存对话原文或工具参数，也不会上传。

`usage.json.cache` 是可重建的增量读取缓存。未变化的日志文件复用已解析结果，新增或变化的文件重新读取，再按事件身份合并；缓存损坏或缺失时会回到完整读取。缓存不保存会话原文，写入失败也不会覆盖已经保存的账本。

读取阶段可取消；进入账本保存阶段后无法取消，界面会明确提示。解析提示会标明未覆盖的部分。无法识别的账本不会被应用重置；遇到启动提示时，先备份应用数据目录，再检查账本格式或联系维护者。当前上限为 64 MiB，超过后拒绝本次写入并保留原文件。

## 从 CLI 查看

在源码目录执行（将路径替换为自己选定的目录）：

```sh
pnpm koyori usage --client claude-code --root ./my-skills --history ./my-history --days 90
pnpm koyori suggest --client claude-code --root ./my-skills --history ./my-history --days 30
```

两个入口共用桌面核心，输出 JSON 报告、覆盖和提示。一次绑定一个资源根，可重复 `--history` 添加多个历史目录。它们只建立临时内存账本，不读写桌面偏好，也不会假设本次首次发现的资源已经观察满 30 天。

退出码 `0` 表示读取完成，仍需看覆盖是否受限；`1` 表示扫描失败或历史来源不可读/不受支持；`2` 表示参数错误。现有 `scan` 仍输出只读资源清单。
