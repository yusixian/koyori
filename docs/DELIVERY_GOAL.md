## 目标与授权

保留 Koyori 的个人工作台定位，实现 Claude Code / Codex Skills 自动发现、持续使用证据、受控跨客户端同步、本地及 Git 备份恢复。同步公开指南，完成 review、CI、合并和文档站部署。此前错误的暂停已被用户明确撤回，工作继续。

允许本仓库实现、测试、提交、push、PR 更新及合并；允许在用户指定 Dokploy 上配置并部署本文档站。没有授权迁移/同步/上传真实个人 Skills、修改现有 Skills Manager 数据、发布桌面正式版本或改造私有 Bot。真实文件写入验证使用隔离合成目录；需要用户参与的登录/权限/域名事项集中记录，继续其他可独立工作。

## 产品契约

- 自动发现标准及兼容目录，支持环境覆盖和手动来源；启动/刷新发现，不要求用户先选择目录。项目仅扫描登记项目，忽略选择持久保存。
- 一个真实文件位置可以供多个客户端发现；区分来源、共享链接、可见性、受管同步和调用证据，不根据文件存在断言客户端已加载。
- 原始目录保持权威；同步复制完整 Skill 目录，包括 scripts/references/assets。先兼容检查和差异计划，执行前重验源/目标，创建恢复快照，回读验证。相同内容跳过，冲突需明确选择；不默默双向覆盖。
- Claude 专有 frontmatter、参数替换、hooks/子代理及外部依赖提示适配风险；不自动移植权限。插件/系统资源保持只读发现。
- 统计单独启用，自动发现历史位置；变更检测与启动补扫，增量缓存避免重复解析。事件去重、覆盖范围、失败/未知与显式请求继续分开。Codex adapter 只认隔离样本能证明的证据，不捏造完整调用次数。
- 本地不可变快照保护每次受管写入；手动完整备份、历史、恢复预览和冲突检查。Git 远端连接/上传/获取历史独立于本地保存，上传后核对远端对象，失败保留本地快照。自动备份可关闭，退出最多本地保存，不阻塞网络。
- 远端备份默认不包含原始会话、凭据和本机路径配置。备份清单说明纳入/排除项；不宣称能自动识别所有写在 Skill 正文里的敏感信息。

## 阶段与退出证据

1. **M2 自动化**：自动发现、来源生命周期、默认扫描、自动历史候选与增量采集。隔离 home/Profile、重复根/链接、断开与重启、日志追加/轮转和去重测试；真实 Electron 首次启动流程。
2. **M3 同步及本地恢复**：完整目录计划、兼容提示、同步、差异、快照/恢复。临时目录验证外部修改、路径越界、部分失败/中断及恢复冲突；GUI/CLI 共用 core。
3. **M3 Git 备份**：连接、快照上传/下载、远端校验、自动备份与重试、断开保留数据。使用合成本地 bare Git 远端做故障/冲突验证；真实账号上传只在单独明确选择后进行。
4. **交付**：公开文档与未发布说明；有界独立审查与修复、定向本地检查、真实桌面验收、精确 SHA 的 CI；review 后合并。Dokploy 部署文档站并验证容器与公网页面、搜索、深链和移动视图。

个人 Agent / Bot / 语音仍属于后续 M4/M5，本次不扩入实现。使用证据与受控计划为其保留调用入口。
