## 独立安装与升级

在临时 Applications 目录安装公开 alpha.2 DMG，使用独立 `userData`、`HOME`、`CODEX_HOME` 和 `CLAUDE_CONFIG_DIR`，不接触日常配置。起点应用显示 `0.1.0-alpha.2`，合成服务书签“升级保留测试”存在。

1. 在应用的“更新”区域点击“检查更新”，返回 `available`，目标为 `0.1.0-alpha.3`。
2. 点击“下载新版”，应用从公开更新源下载 139,708,133 字节的 ZIP，状态变为 `ready`。
3. 点击“重启并安装”；原应用退出，原安装位置的应用版本变为 `0.1.0-alpha.3`。
4. 用相同隔离配置重新启动，更新控制器报告 `currentVersion: 0.1.0-alpha.3`，合成服务书签仍存在。结果：**应用内升级与此项持久数据保留通过**。

此机器的 `codesign --verify --deep --strict` 对 alpha.1 和升级后的 alpha.3 都返回 `CSSMERR_TP_NOT_TRUSTED`；本机没有独立证明证书链受信任。发布流水线验证了 Apple Development 签名的归档；此记录只证明上述机器上的实际更新行为，不把未公证 Preview 称为正式分发验收。Dokploy 站点未部署，此记录也不代表线上下载页已提升到 alpha.3。
