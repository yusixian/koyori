## 应用内升级尝试

从上一轮验收留下的公开 alpha.3 临时安装出发，测试脚本传入临时用户数据目录和合成服务书签。应用检查到 `0.1.0-alpha.4`，下载后状态到达 `ready`。点击“重启并安装”后，安装器记录请求，但在两分钟内没有完成替换，应用目录仍为 alpha.3。后续只读排查发现，同路径的旧实例仍在运行，其子进程使用日常配置目录；因此这次运行不具备完整的数据隔离，**没有通过安装与数据保留验收**。现有证据不足以确定安装停住的单一原因。

已停止当时新启动的一个待安装辅助进程，并将其暂存状态移出活动更新缓存、保留到临时恢复目录。后续只读排查仍发现另一个 ShipIt 辅助进程运行；其活动缓存与暂存状态已分叉，不能据此断言待安装状态已彻底清除。未退出那个仍在运行、已连接日常用户目录的旧实例，也未再操作更新缓存。后续应在全新的 macOS 测试用户或隔离虚拟机中重新执行安装、重启和合成数据保留检查；开始前须核对应用子进程和更新缓存都落在隔离环境。

Apple Development 签名仍未公证。本页不将公开下载、归档验收或不完整的升级尝试称作正式分发验收。
