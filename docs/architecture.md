# 架构与数据设计候选

> 2026-09-09 初稿；长期设计候选，允许 MVP 内调整。当前已实现范围见 [实施状态](implementation-status.md)。

## 结构与进程

建议模块化单体：Electron 界面和 CLI 连接同一个本地核心运行时，统一协调写入。核心由桌面进程托管或按需启动，首版不要求开机服务。必须明确单实例发现、通信权限、空闲退出及重连行为。

```text
apps/desktop    Electron main、preload、renderer
apps/cli        人与 AI 的入口
apps/site       官网、文档、下载与更新日志
packages/core  扫描、作用域、任务、操作、存储、客户端适配
packages/contracts  类型、能力与本地通信契约
```

apps/desktop、apps/cli、apps/site 和 packages/core 已建立；packages/contracts 仍是候选，当前桌面 bridge 类型保持在应用内。核心不依赖 UI、云 SDK 或具体模型。renderer 沙箱化，通过窄接口访问主机能力，扫描解析运行在独立 worker；API/ACP 运行时仍待后续验证。

## 数据权威与存储

| 数据 | 权威与存储 |
| --- | --- |
| 外部 Skills/commands/指令/MCP 配置 | 用户磁盘文件；工作台只观察或经计划修改 |
| 标签、收藏、项目、规则、草稿、操作记录 | 持久应用数据，建议 state.sqlite |
| 自有收藏库 | 持久 library，包含完整资源包 |
| 索引、解析与预览 | 独立 index.sqlite 和缓存目录，可重建 |
| 历史快照 | 独立持久 history，有保留策略，不是缓存 |
| API Key 等 | 系统凭据存储或安全引用，不进入普通 DB/日志 |

当前只持久化来源设置，使用应用数据目录内带版本号的 JSON；尚无数据库。后续考虑 SQLite，驱动、ORM 与具体路径待需求确定。缓存与持久库不要求跨库原子提交，缓存引用丢失或过期不破坏源数据。若采用 WAL，维护 checkpoint，不直接删除正在使用的 WAL 文件。

## 核心实体

| 实体 | 作用 |
| --- | --- |
| spaces | 默认本地资源空间，保留未来共享归属 |
| projects | 项目身份、根目录与扫描设置 |
| client_profiles | Claude/Codex 配置根与运行入口 |
| targets | Profile 在项目或全局的操作作用域 |
| resources | 稳定 ID、类型、来源、用户元数据 |
| resource_locations | 原件、链接、部署副本、设备路径 |
| bindings | 目标上的期望启用/部署策略 |
| observations | 时间、hash、解析、推断与验证状态，可重建部分归缓存 |
| operations / operation_steps | 计划、文件版本、恢复引用、执行阶段 |
| jobs | 扫描、连接与分析任务，支持取消 |
| ai_runs / recommendations | 用户选择的证据、执行来源、结果与采纳 |

先按真实功能逐步建表。资源 ID 不等于名字、路径或内容 hash；移动关联不明确时提示，不自动合并同内容独立资源。期望状态、磁盘观察状态与客户端运行状态分开。

## 操作与一致性

GUI、CLI、AI 调用同一能力层：名称、schema、作用域、只读/计划/执行级别、错误与取消语义。宿主记录授权，不能接受模型自填 confirmed=true；CLI 也不能仅以“来自本机”判断写入权限。

计划 → 核对文件 revision → 保存恢复材料 → 逐项执行 → 重新读取验证 → 完成 journal。多文件修改不是数据库事务，记录部分成功并在重启后核对实际状态。恢复也验证文件是否在执行后又被修改，不盲目覆盖。扫描可安全重试，写入重试必须先识别上次结果。

自动任务合并事件并去重，外部编辑更新观察状态，不由旧期望值自动覆盖。未知配置先只读。阶段性测试目录替换、权限失败、链接和写入中断等关键边界，不构造过度通用事务框架。

## 容量与清缓存

仅清本应用登记的可重建缓存类别。不能删除整个 userData、共享目录、用户工作区构建缓存、Skills 或混有用户状态的数据库。执行接口接受类别 ID，不接受任意路径/glob/shell。

清理前列大小和重建影响，暂停写入/切换缓存代际，核对路径边界并避免链接/替换竞态，忙碌项跳过或延迟。清理后恢复索引服务，报告结果。缓存设大小/期限，日志轮转，遗留临时文件按所有权回收。备份与草稿独立保留，不因缓存限额被清理。

## 商业化接缝

本地安装/空间 ID 与未来账户分开；资源归属与设备路径分开。核心保留能力权益与可选云接口，但不实现支付平台。套餐权益、操作权限、客户端能力、环境可用性分别判断。

未来远程服务验证权限和额度，本地用量不作收费权威；BYOK/本地 ACP 与托管推理分开。同步声明不带绝对路径和凭据，不能直接同步数据库。前期仅一个默认本地空间；成员、订阅、远程身份等按实际需求新增。

内部 schema 和接口在 alpha 允许变动，缓存可重建；持久用户数据变更须明确升级或提示备份处理，不承诺无限兼容或任意降级。
