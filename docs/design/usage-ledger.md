# Skills 使用账本：当前实现

> 2026-09-22；M2 实现记录。验收结果以 [实施状态](../implementation-status.md) 为准。

## 入口与计数

Skills 目录和历史目录分别选择。历史来源绑定一个资源根；当前桌面支持 Claude Code JSONL 会话目录，递归读取其子目录中的记录。不自动查找全部账号，不安装 hook，不调用云端模型 API。

| 记录 | 展示 |
| --- | --- |
| assistant 消息中 `tool_use`，工具为 `Skill` | 一次调用尝试 |
| 对应 `tool_result`，未标记错误 | 成功返回；不代表任务完成或 Skill 有效 |
| 对应结果 `is_error: true` | 失败 |
| 没有结果或结果冲突 | 结果未知 |
| 受支持的直接命令请求标记 | 单独的显式请求；不补成已加载 |
| 文本提及、资源注入、Read 读取 SKILL.md | 不计调用 |

以工具事件身份去重，结果用于补齐已有事件。复制记录不重复加次数；冲突保留诊断。会话键只保存摘要，子代理单独区分；无法确认时，会话数只作为已知下限。按当前来源、客户端与精确名称匹配，重名无法唯一归属时单列，历史名字不证明当前文件的历史版本。

Codex 0.155.1 本地 App Server schema 可以表达结构化 Skill 请求，但资源列表与请求都不能替代完整历史调用次数。当前 Codex 仅支持资源扫描，未实现统计适配器，界面保留未知。参考 [Codex App Server](https://learn.chatgpt.com/docs/app-server) 和 [Claude Code hooks](https://code.claude.com/docs/en/hooks)；本实现不依赖安装 hooks。

## 证据与覆盖

统计提供近 30 / 90 天窗口、调用尝试/成功返回/失败/未知/请求、已知会话数与最近调用。每项最多展开最近十条事件，显示时间、相对日志文件和行号；不显示对话原文或工具参数。

覆盖区显示采集器版本、实际遇到的客户端版本、可读文件/记录数、时间范围、坏行、跳过文件与读取限制。日期跨度不证明期间完整；所选记录中 0 次不代表从未使用。按需重复扫描并合并去重；当前不做实时监听或文件偏移增量读取。

输入有文件数、字节、单行、递归深度和事件数量上限，触及上限时保留覆盖缺口。最多读取 5,000 个文件、256 MiB、250,000 条记录和 50,000 个事件；单文件 32 MiB、单行 2 MiB，诊断最多 1,000 条。子路径符号链接不跟读，打开文件前后核对路径与文件身份；导入在 worker 中执行，可取消。断开来源后不再读取，已采集证据保留。

## 规则与偏好

“始终保留”保护资源不进入闲置/低频/重复整理候选；“稍后复查”保存复查日期。相同内容建议只比较完整、未截断文件，排除指向同一实际文件的共享引用。

默认闲置观察期 90 天、低频阈值 2 次、新发现观察期 30 天，用户可修改。首次观察不是安装日期；新发现资源不因旧日志立即判为长期闲置。闲置/低频规则要求当前每个已连接来源的记录跨度达到规则天数、起点覆盖规则窗口、末端在最近七天内（规则天数不足七天时按该天数），且本次没有受限读取；仅有旧日志、来源不足或归属不清时不生成该类候选。固有的“历史可能不完整”说明会保留，但不会阻止已满足门槛的复查建议。建议只提示复查，不删除、不部署、不归档。

应用内每七天提醒重新检查建议；人工标记“本次已复查”后重新计时。这不是后台定时任务或系统通知。当前没有 AI 推荐调用。

## 持久数据与安全

桌面主进程独占应用数据目录内的 `usage.json`：版本、用户选定来源、最小事件、覆盖、问题、偏好和规则。内容先校验，再写入权限为 0600 的临时文件、同步、保留上一份 `.bak`，最后原子替换。损坏或未来版本拒绝加载并保留原文件，不静默重置。账本容量上限 64 MiB，超限拒绝本次写入，不丢弃旧证据。

这份账本不是缓存。包含本机路径、Skill 名称、事件时间与使用偏好，即使没有原文也应当作个人数据；不要上传到公开 issue。读取阶段可取消；进入原子保存阶段后会明确拒绝取消。失败不覆盖上次有效账本；原会话和 Skill 文件始终只读。无遥测、网络上传或付费探测。

当前 JSON 方案服务单机小规模证据记录，不承诺无限容量或多进程写入。CLI 独立读取用户指定目录并输出报告，不写桌面账本。后续如迁移 SQLite，需提供备份、导出和恢复验证，不能借迁移丢掉唯一历史证据。
