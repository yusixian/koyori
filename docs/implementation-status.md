# Koyori 实施状态

> 2026-09-22；M1 工程起点与 M2 Skills 使用账本已实现。公开仓库为 [yusixian/koyori](https://github.com/yusixian/koyori)，尚无公开发行版。

## 当前迭代

让 Skills 从“看清单”进入“看真实使用证据，再决定保留或复查”：Claude Code 本机历史适配器、30/90 天账本、规则与偏好、共用 CLI 和公开指南。Sol 编写适配器、统计/CLI、界面及有界边界检查；主代理负责契约、持久化、桌面集成与最终验证。

完整 0.1 仍包括可恢复整理、个人 Agent/Bot 连接和发布分发。M2 完成不等于完整首版交付。当前不修改私有 Bot，不部署生产，不发布公开安装包。

## 当前能力

- 用户选择 Claude Code/Codex Skills 目录，扫描、搜索、筛选、纯文本预览；来源设置本机保存，扫描可取消。
- 另行选择 Claude Code JSONL 历史目录，导入结构化 Skill 尝试与对应结果；显式请求单列，文本提及和文件读取不算调用。
- 跨文件复制去重、后续结果补齐、失败/冲突/未知状态；按来源和精确名称唯一归因，重名事件单列。
- 显示实际覆盖、版本、坏行、跳过和读取上限；Codex 使用历史仍未支持，不显示虚假零调用。
- 保留、30 天后复查、到期提醒、相同内容与闲置/低频候选；阈值可改，新发现日期不冒充安装日期。
- 版本化本地账本、上一份备份、失败保留与重启恢复；断开/移除来源不删除原 Skill、日志或已采集证据。
- CLI `scan`、`usage`、`suggest` 复用相同核心；统计命令使用临时内存账本，不改桌面偏好。
- 独立文档站新增统计指南，下载页保持无公开发行版状态。Agent/服务页面继续标明未接入。

具体口径与持久边界见 [账本实现](design/usage-ledger.md)，用户入口见 [使用指南](../apps/site/content/docs/skill-usage.mdx)。

## 验证记录

本轮已取得的本地证据如下；CI、候选包和生产验证分别记录。

- 实际 Electron：目录选择、扫描、导入、复制日志去重、证据展开、保留/复查、断开和重启保留流程通过；原 Skill/历史未修改，最小账本不包含合成会话原文哨兵。
- 200 个合成 Skill / 10,000 次事件，本机 Node 22.23.2、macOS ARM64：扫描约 199 ms，导入约 84 ms，合并与报告约 63 ms。单次核心测量，不代表所有机器、GUI 或大型个人日志的性能。
- Node 22.23.2：42 项定向测试通过，涵盖导入、去重、状态冲突、覆盖、规则、CLI、持久化和 IPC；格式、类型与桌面/站点构建通过。
- 真实 Claude 小样本：7 个 JSONL、4,536 条记录，客户端版本 2.1.274 / 2.1.276 / 2.1.278；10 次尝试、10 次成功返回，与独立解析一致，0 坏行/跳过/受限读取。读取前后摘要一致。失败、复制/分叉、严格请求和恶意输入边界由合成测试补充，不把小样本视为所有客户端路径已验证。
- 站点静态构建和新指南桌面/移动深链已经检查，搜索入口随新增页面同步。
- 基础公开文件检查通过；未引入真实会话 fixture、Bot 私有实现或第三方 Skills Manager 代码。

全量回归、文档容器与打包后应用验收由每次提交的 [GitHub Actions](https://github.com/yusixian/koyori/actions) 执行；请核对对应 SHA 的最终结果，不能沿用上一轮结果作为新代码的证明。候选清单记录版本、commit、工作区状态与安装包摘要。

尚未部署 Dokploy、签名、公证或验证跨公开版本升级。候选仅面向 Apple Silicon macOS；未签名候选不是正式发行版。
