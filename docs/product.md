# 产品范围

> 2026-09-22 更新定位与发布要求；所有产品功能尚未实现。

首版范围按 [0.1 MVP 草案](design/mvp-0.1.0.md) 推进；本文保留较完整的长期能力，未进入该草案的功能不自动成为首版要求。

## 定位

Koyori 是自用优先、探索性质的 AI Native 个人工作台，从首版按开源项目建设。首个平台为 macOS / Electron，既探索 Claude Code、Codex 资源管理，也探索接入已有个人服务的 GUI 与窄能力；保留可配置目录与 Profile。用户已提出首版包含个人 Agent 和 cos-tool-bot 接入；具体按扩大版草案审阅，语音深度待确认。聚合告警首页、插件市场、完整会话编排和内嵌终端不是默认范围。

版本管理、Dokploy 文档站、下载与更新说明、安装包验收从工程初始化开始建设，见 [发布与开源基线](design/release-foundation.md)。下文是 AI 资源管理模块的规划，不代表工作台全部功能必须一次实现。

## 五类资源

| 对象 | 功能 |
| --- | --- |
| MCP | 查看、新增、编辑、项目/Profile 配置启用或禁用、主动连接测试、恢复 |
| Skills | 收藏、来源与资源预览、项目按需启用/停用、编辑及恢复 |
| Claude commands | 发现、预览、新建、编辑、项目部署及撤销部署 |
| 指令文件 | 全局、项目、子目录 AGENTS.md / CLAUDE.md 及客户端相关文件的发现、作用域解释、编辑与恢复 |
| 普通 Markdown | 全部扫描模式、分类、目录树、文件名/全文搜索、预览和编辑 |

全局资源和项目视图是两个主要入口。展示来源、目标客户端、路径、继承关系与实际影响范围。普通 Markdown 被索引不代表它会被客户端加载，也不自动发送给模型。

## 按需可见性

- Skill 默认隐藏、需要时仅在当前项目启用。使用已验证的客户端原生禁用策略，或非扫描收藏库加项目链接/副本。
- 原件仍在全局扫描目录时，撤掉项目链接不能实现隐藏；显示全局残留、重名和插件来源。
- 完整部署 Skill 目录，保留脚本、附属资源和相对引用；停用不等于删除收藏源。
- 区分不可见、仅手动调用、禁止调用与未安装，不用一个含糊的 enabled 字段掩盖差异。
- 关闭 Skill 不会清除旧会话历史；以新会话验证上下文变化。
- 项目部署可能影响同项目的多个 Profile/会话，不能虚构隔离。
- 未验证原生禁用的 command 使用撤销受管部署；现有外部资源接管先生成计划。插件来源首版识别并引导客户端原生管理。

MCP 配置开关、连接状态和进程生命周期分别展示。客户端持有的 stdio 管道不是工作台另起进程就能接管；远程 HTTP 禁用只控制本客户端连接。显示待重载与未知状态，只停止明确归工作台所有的进程。

## 自动发现

监听登记的资源根、配置根与项目目录。启动扫描、事件合并、稳定读取、hash 去重、增量更新，唤醒或异常后重新核对。识别新增、修改、删除、移动和链接变化。

- 默认过滤依赖与缓存，显示排除项；完整模式覆盖所选根内被排除的 Markdown，读取失败明确列出。
- 扫描隐藏目录及嵌套项目，按位置与元数据识别 Skill/command，不能只根据文件夹名猜测。
- 链接记录目标并检测循环，跨根引用不自动扩展读取范围。
- 文件集合视作快照，无法推断未提供的全局/父目录内容或持续监听原件。
- 应用/托盘运行时监听，退出后下一次启动补齐；暂不安装系统 daemon。
- 自动登记、检查、分类和通知，不默认运行模型、部署资源或启动 MCP。
- 外部直接新增到全局目录的 Skill 可能已生效，应准确显示，不声称工作台开关能阻止客户端发现。
- 批量变化进入变更收件箱；自身写入关联 operation ID/hash，防止同步循环。

## AI Native

CLI 是一等入口，与 GUI 同用核心能力；模型按需获取应用说明、能力 schema、当前选择和查询结果。拟定能力包括 describe、selection、inventory query、instructions explain、storage inspect、changes plan/apply。

AI 后端分为 API Key 文本调用与本地 ACP Agent。ACP 负责会话交互，不自动提供应用按钮或配置管理；适配后暴露同一核心能力。没有 AI 配置也能完成基础资源管理。本地 Agent 不代表模型推理离线。

首批 AI 功能候选：精简但保留约束、重复/冲突分析、触发描述优化、作用域调整、相同任务前后试验。AI 输出候选及理由、证据、diff，再采纳。ACP 权限边界必须实际生效，不依靠“不要修改文件”的提示词。

## Skills 使用统计与整理建议

使用账本是基础能力，不依赖 AI：按客户端、Profile、项目与时间窗口展示明确调用次数、去重会话数、最近使用及证据覆盖。显式请求、读取线索和仅提及分开记录；日志缺失或无法归因不能显示成确定的零调用。

机械规则支持长期闲置、低频、复查到期和重复候选，阈值可调，提供保留及稍后提醒。应用运行时定期检查，退出后启动补查；自动建议不等于自动执行。扩大版首版提议由 Agent 结合用户选择的内容、历史摘要和项目需求，解释保留、改进触发描述、缩小作用域或归档的理由，不能编造调用次数。

清理建议必须包含来源、观察窗口、当前部署/引用、影响与不确定性。同名插件能力不视为等价替代，Skill 未调用也不证明整个插件无用。永久删除单独确认，绝不混进缓存清理。采集入口、规则和分期见 [Skills 使用统计与整理建议](skill-lifecycle.md)，均为待验证候选。

## 资源模块的长期验收范围

首版以 [扩大版 MVP 的验收](design/mvp-0.1.0.md#11-完成与测试标准) 为准。下述覆盖范围随五类资源逐步落地，再验证编辑恢复、MCP 配置和项目部署。验收覆盖两个项目、不同 Profile、嵌套指令、带资源 Skill、command、坏配置与链接；验证项目 A 操作不意外影响 B，并解释共享来源。

少量关键用例保护并发编辑、恢复冲突、清缓存越界和中断后状态。实际运行时可见性须在隔离新会话验证；静态结果不能冒充已加载。当前没有任何产品验收结果。
