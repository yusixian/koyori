# v0.1.0-alpha.1

这是 Koyori 首个面向本机测试的 macOS Apple Silicon Preview。它以本地 Skills 管理和自配模型 Agent 为基础，并加入了用户控制的版本检查、应用内下载和重启安装更新。

## 新增

- 自动发现 Claude Code 与 Codex Skills，预览完整目录同步，建立本地备份并按计划恢复。
- 选择一项 Skill，预览经过白名单限制的使用证据摘要，再加入 Agent 草稿并手动发送。
- 配置 OpenAI-compatible 模型连接，管理本地会话、流式回复、取消和未知用量状态。
- 桌面应用使用标准更新元数据检查 Preview，用户确认后在应用内下载并重启安装。
- 文档站提供下载状态、版本记录和安装说明，并展示与公开清单绑定的 SHA-256 和构建 commit。

## 安装与限制

- 目标平台：macOS 13+、Apple Silicon（arm64）。
- 分发要求：Developer ID 签名与 Apple 公证，并使用最终产物验证首次安装；真实升级证据单独记录。
- 应用自动检查新版，也可手动检查；下载和重启安装由用户点击触发，普通退出不会触发安装。
- 这是首个公开候选，没有上一公开版本可供升级路径验证。

下载页与公开清单提供同一份产物的文件大小、SHA-256、构建 commit 和完整 GitHub Release 地址。
