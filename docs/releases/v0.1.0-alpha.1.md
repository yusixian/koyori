# v0.1.0-alpha.1

这是 Koyori 首个面向本机测试的 macOS Apple Silicon Preview。它以本地 Skills 管理和自配模型 Agent 为基础。首个公开候选计划使用 Apple Development 签名、未公证的手动安装方式；Developer ID 公证和应用内更新继续作为后续能力准备。

## 新增

- 自动发现 Claude Code 与 Codex Skills，预览完整目录同步，建立本地备份并按计划恢复。
- 选择一项 Skill，预览经过白名单限制的使用证据摘要，再加入 Agent 草稿并手动发送。
- 配置 OpenAI-compatible 模型连接，管理本地会话、流式回复、取消和未知用量状态。
- 桌面应用已准备标准更新元数据与用户控制的下载流程，但首个手动安装候选不启用应用内更新。
- 文档站提供下载状态、版本记录和安装说明，并展示与公开清单绑定的 SHA-256 和构建 commit。

## 安装与限制

- 目标平台：macOS 13+、Apple Silicon（arm64）。
- 首个候选若以 Apple Development 签名方式发布，下载页会明确标注“已签名，未公证”；通过 DMG 手动安装和替换，macOS 可能要求在“隐私与安全性”中手动允许打开，不具备应用内自动更新。
- 最终产物仍须完成首次安装验收。真实升级证据在存在上一公开版本后单独记录。
- 这是首个公开候选，没有上一公开版本可供升级路径验证。

下载页与公开清单提供同一份产物的文件大小、SHA-256、构建 commit 和完整 GitHub Release 地址。
