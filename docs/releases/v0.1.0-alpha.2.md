# v0.1.0-alpha.2

这是 Apple Silicon macOS Preview 的更新候选。它为 Apple Development 签名的应用加入 alpha 更新源和应用内更新元数据。实际公开状态以 GitHub Release 和下载页为准。

## 改进

- Apple Development 签名候选同时提供 DMG、ZIP、blockmap、`alpha-mac.yml`，应用内包含 `app-update.yml`。
- 下载页清单会区分已签名未公证的应用内更新候选与手动安装包；发布校验检查更新元数据和全部产物摘要。
- 后续 Preview 可以在同一 alpha 渠道检查新版，由用户决定下载和重启安装。普通退出不会自动安装。

## 安装与限制

- v0.1.0-alpha.1 没有应用内更新源。使用 alpha.1 的用户须下载本版 DMG，退出旧版后手动替换一次。从本版开始才具备检查后续 Preview 的配置。
- 目标平台为 macOS 13+、Apple Silicon（arm64）。Apple Development 签名尚未公证，首次打开可能需要在“隐私与安全性”中手动允许；这不是正式的 Developer ID 分发。
- 归档安装、启动和文件摘要由候选发布流水线验收。alpha.1 无法作为应用内升级起点，首次真实应用内升级及数据保留仍需在后续两份带更新源的安装包之间验证。未获得该证据前不宣称升级已验收。
