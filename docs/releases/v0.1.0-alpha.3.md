# v0.1.0-alpha.3

这是 Apple Silicon macOS 的 Apple Development 签名、未公证 Preview。此版为从带更新源的 v0.1.0-alpha.2 验证应用内升级提供目标版本；实际升级结果以独立验收记录为准。

## 改进

- Preview 发布流水线在新建 draft Release 后等待其可见，再上传同一份已验收的产物，避免短暂的 GitHub API 可见性延迟中断发布。
- 下载页明确说明：从不含更新源的旧版迁移时，须先用 DMG 手动替换；此后的 Preview 才能在应用内更新。

## 安装与限制

- 目标平台：macOS 13+、Apple Silicon（arm64）。Apple Development 签名未公证，首次打开可能需要在“隐私与安全性”中手动允许。
- v0.1.0-alpha.1 不含更新源，只能用 DMG 手动升级。已安装 v0.1.0-alpha.2 的用户可以在应用内检查本版，下载后自行确认重启安装；普通退出不会自动安装。
- 没有新增 Skills 或 Agent 功能。应用内升级和持久数据保留是否通过，须以真实安装后的验收记录为准，不能从发布成功推断。
