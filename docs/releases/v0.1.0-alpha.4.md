# v0.1.0-alpha.4

这是 Apple Silicon macOS 的 Apple Development 签名、未公证 Preview。本版集中调整应用界面与滚动体验，不改变 Skills 文件操作、模型请求或更新协议。

## 界面改进

- 侧栏的“更新”改为独立页面，完整显示当前版本、预览渠道、检查结果、下载进度及安装操作；窄窗口不再把更新状态挤在侧栏底部。
- 切换工作台页面和 Skills 视图时回到新页面顶部；长列表的视图切换入口保持可见，窄窗口查看 Skill 详情后可返回原清单位置。
- Agent 首次打开时直接展示会话区，连接表单按需打开；长对话在消息区滚动，输入框随内容增长，阅读旧消息时不会被新内容强制拉回底部。
- 使用证据空状态与管理操作区收紧排布；服务空列表可直接跳到新增表单。统一表单控件、复选框、焦点反馈、字号与中文栏目提示。

## 安装与限制

- 目标平台：macOS 13+、Apple Silicon（arm64）。Apple Development 签名未公证，首次打开可能需要在“隐私与安全性”中手动允许。
- v0.1.0-alpha.1 没有更新源，仍须通过 DMG 手动替换。已安装带更新源的 Preview 可以在侧栏“更新”页检查、下载并确认重启安装；普通退出不会自动安装。
- 发布候选的归档验收与公开版本之间的实际应用内升级分别记录；不能仅从发布成功推断升级和数据保留已经通过。
