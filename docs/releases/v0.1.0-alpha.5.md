# v0.1.0-alpha.5

这是 Apple Silicon macOS 的小幅 Preview 更新，沿用 Apple Development 签名、未公证的分发方式。本版只调整 Skills 界面的首次使用体验，不改变 Skill 文件、使用账本或同步行为。

## Skills 界面

- 打开资源清单时，直接看到简短的起点和一个查看 Skill 的操作；没有发现资源时可先打开合成示例。
- 清单把最近有使用线索的 Skill 排在前面，每次先显示 20 项，搜索仍覆盖全部资源。
- 使用页先展示有记录、已设置偏好或待复查的 Skill，需要时仍可查看全部。
- Skill 详情说明应在对应的 Claude Code 或 Codex 中使用；Koyori 的 Agent 不会自动调用清单中的 Skill。

## 安装与限制

- 目标平台：macOS 13+、Apple Silicon（arm64）。Apple Development 签名未公证，首次打开可能需要在“隐私与安全性”中手动允许。
- 已安装带更新源的 Preview 可从应用内检查并下载新版本，随后自行确认重启安装；实际升级和数据保留以单独验收记录为准。也可以从下载页获取 DMG 手动安装。
- Codex 仍只支持 Skill 资源盘点，不提供可靠的历史调用次数；未采集不表示零使用。
