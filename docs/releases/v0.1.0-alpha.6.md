# v0.1.0-alpha.6

这版 Preview 改善自配模型连接的排查与选择体验，面向 macOS 13+ 的 Apple Silicon 设备。

## Agent 连接

- 连接设置新增“测试连接”和“获取模型”。两者只请求当前草稿地址的 `GET /models`，不会保存草稿或发起推理；获取的模型 ID 可点选后再保存。
- 相同服务地址下更换模型时，可沿用已安全保存的 API Key；更换服务地址时须重新填写密钥。
- 对模型服务的 HTTP 错误展示状态码及经过截断、脱敏的标准错误字段。DNS 阶段失败会明确提示请求尚未发出。
- 兼容把外部 HTTPS 域名解析到代理虚拟地址段的本机网络；直接填写该地址及其他受限网络仍会被拒绝。

## 安装与限制

- Apple Development 签名、未公证；首次打开可能需要在 macOS“隐私与安全性”中手动允许。应用内更新与数据保留情况以对应验收记录为准。
- 连接测试依赖服务的 `/models` 接口，不验证所选模型的对话能力；不提供模型列表接口或使用其他发现路径的服务仍可手动填写模型 ID。
- 真实付费模型服务的鉴权和计费尚未作为自动验收的一部分。
