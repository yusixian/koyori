# v0.1.0-alpha.7

这版 Preview 完善 Skills 整理建议与 Agent 之间的核对流程，面向 macOS 13+ 的 Apple Silicon 设备，沿用 Apple Development 签名、未公证的分发方式。

## Skills 与 Agent

- 单 Skill 摘要新增“返回使用证据”，沿用摘要的 30/90 天观察窗口打开账本证据区；返回时保留摘要和已有草稿，不自动发送消息。没有记录或来源不可用时说明原因。
- 相同内容 Skill 候选可并排核对客户端、作用域、证据覆盖、保留/复查与链接关系，并分别打开详情。未知信息明确标注，不自动归档或删除。
- Agent 显示所选 Skill 的本机明确偏好、来源与状态，可打开“使用与建议”核对记录。撤销保留或复查标记须先预览再确认；取消不写入，首次观察日期保留，确认前重新核对资源与偏好。

## 开发与文档

- `pnpm dev` 的桌面页面默认从本机端口 `15173` 开始，冲突时自动选择可用端口；打包应用不监听这个端口。
- 整理实施状态、路线图和历史交付记录，区分公开版本、main 进展及剩余验收。

## 安装与限制

- Apple Development 签名尚未公证，首次打开可能需要在 macOS“隐私与安全性”中手动允许。可从下载页获取 DMG；alpha.1 不含更新源，须通过 DMG 手动替换。
- 已安装带更新源的 Preview 可在应用内检查、下载并确认重启安装；实际升级与数据保留以独立验收记录为准，发布成功和归档验收不能替代升级验收。
- Git 远端备份仍只有隔离仓库往返证据，真实外部账号验收尚未完成。Codex 仍只支持 Skill 资源盘点，不提供可靠的历史调用次数。
- 本地偏好操作不修改 Skill 文件，也不向模型发送数据；模型回复不会授予操作权限。Bot 配对、通用工具操作卡和语音仍待实现。
